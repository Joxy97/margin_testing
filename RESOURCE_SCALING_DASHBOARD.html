Memory confidence. Graph counts are analytic for fixed union density. FP32 VRAM follows the measured formula. FP64 VRAM expands solver values and state tensors while preserving 32-bit CSR indices. Peak RAM uses the empirical β coefficient and can change if packing is refactored.

Time confidence. The bundled reference is the mean of the current 10-asset diagnostics: 0.11105 seconds per scenario at 1,000 steps and 16 runs. It is launch-bound and is not a reliable large-universe anchor. Replace it with a one-day, one-scenario measurement from the target GPU.

Multi-GPU behavior. The current orchestrator shards dates. GPUs do not split scenarios within one day, so effective GPUs are min(GPUs, days). Every active worker builds its own day and consumes its own process RAM.

Not modeled. Market-data duplication, allocator fragmentation beyond η, OS processes, output I/O, PCA, QUBO construction time, decoding, thermal throttling, and GPU-to-GPU variation are outside the formulas. Treat the result as a planning envelope, then validate with diagnostics.
