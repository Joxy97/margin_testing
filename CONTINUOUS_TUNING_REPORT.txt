Protocol and physical meaning
Each seed gets one fresh solver/RNG state and one uninterrupted 20-second solve.
Record only scalar incumbents at 0.05, 0.1, 0.2, 0.5, 1, 2, 5, 10, 20 seconds.
Checkpoints never restart search; carry naturally returned incumbents forward.
Mutable control ramps use elapsed solve time / 20; 10,000,000 steps is a guard.
Integration time_step is a numerical dynamics increment, not host seconds.
This changes earlier finite step-based schedules, while preserving force equations,
source objectives/dimensions and native padding. References enter metrics only.

Exactly three quality metrics and comparison formulas
Gap=best_energy-reference in signed raw units. Proven hits require equality;
BKS hits allow energy<=reference. Below-proven values trigger validation alarms.
Failed trials stay in the hit denominator; incomplete gap means are unavailable.
TTS99(t)=t*ln(0.01)/ln(1-p(t)); p=0 Inf (diagnostic JSON null), p=1 literal limit0.
dGap=winner_mean_gap-baseline_mean_gap; dP=winner_p-baseline_p.
dTTS=winner_TTS99-baseline_TTS99 only when both values are available.
No percentage threshold, 1% success or time-to-target enters selection.
